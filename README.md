## ⚡ Core Services

1. **Security Guard Services:** Disciplined unarmed security guards for gate access control, visitor and vehicle register maintenance, daytime patrolling, and nighttime property vigilance.
2. **Manpower Supply:** Dependable non-technical commercial staff including office boys, warehouse helpers, facility housekeeping attendants, and general helpers.
3. **Industrial Security:** Gatekeeping, raw material inward/outward gatepasses, delivery challans, truck checks, and plant perimeter vigilance.
4. **Event Security & Crowd Management:** Organized entry management, attendee queue discipline, ticket validation, and orderly crowd coordination.

## 🚀 Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, SSG statically pre-rendered)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (exact pixel-sampled brand navy `#01172F` and safety orange `#FE8100`)
- **Typography:** `Plus Jakarta Sans` (Headings) + `DM Sans` (Body) + `Noto Sans Devanagari` (Hindi)
- **Icons:** Lucide React line icons + custom SVG service icons matching visiting card
- **Internationalization:** Instant client-side English ⇄ हिन्दी (Hindi) toggle
- **SEO & Schema:** Full `LocalBusiness` JSON-LD schema with Bhopal geo-coordinates, XML sitemap, and robots.txt

## 🛠️ Local Development

```bash
# 1. Install dependencies
pnpm install

# 2. Run local development server
pnpm dev

# 3. Build production release
pnpm run build

# 4. Start production server
pnpm start -p 3000
```

---

## 🌐 Deploying to Vercel

1. Import this repository in [Vercel](https://vercel.com).
2. (Optional) Add your `RESEND_API_KEY` in Environment Variables to receive quote inquiries directly via email.
3. Add your custom domain (`covers365.in`) in Vercel project settings.
